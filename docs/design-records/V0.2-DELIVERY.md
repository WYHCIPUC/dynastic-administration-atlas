## 4. 排障记录（复用知识）

- **Git Bash curl 中文 body 是 GBK**：`curl -d '{"rawText":"护士"}'` 发出 GBK 字节，服务器端变乱码致 exact 全失配、联想结果顶替——**不是 matcher bug**。中文请求体必须 `--data-binary @utf8file` + `charset=utf-8`。
- Windows node 解析 `/tmp` 为当前盘根（Y:\tmp），与 Git Bash 的 /tmp 不同；跨进程传文件用管道或绝对路径。
